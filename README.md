# Occupancy Tracker

A Java application that tracks the number of people inside a building and displays its current occupancy level.
The project is designed to grow from a simple console application into a real world occupancy management system.

## Status

Version 1 is currently in development. The project is focused on building a reliable occupancy tracking system 
using manual input before adding automation and analytics.

## Current Features

- Project setup

## Version 1 Goals

- Manually record people entering and exiting
- Display the current occupancy
- Display an occupancy percentage bar
- Allow manual occupancy corrections
- Record and display occupancy event history
- Configure the building's reference occupancy level

## Project Purpose

The Occupancy Tracker is an application designed to monitor how many people are currently inside a building.
The goal is to provide businesses with a simple way to monitor and display the building occupancy, allowing 
employees and customers to understand how busy a location is.
Version 1 plans to design a reliable occupancy tracking system using manual inputs. Future versions will 
replace manual inputs with automated camera detection, allowing the system to track occupancy in real time
and collect historical data for business analytics.
