# Occupancy Tracker

A Java application that tracks the number of people inside a building and displays its current occupancy level.

## Status

🚧 Early development

## Current Features

- Project setup

## Planned Features

- Track people entering
- Track people exiting
- Display current occupancy
- Display occupancy percentage
- View occupancy history
- Save/load occupancy data
- Statistics and analytics
